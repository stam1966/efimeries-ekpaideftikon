# Εφημερίες Εκπαιδευτικών Portable — v0.32

Η εφαρμογή οργανώνει και παράγει πρόγραμμα εφημεριών εκπαιδευτικών σε Windows, ανά ημέρα ή ανά διάλειμμα, με ετήσια ισοκατανομή, διαθεσιμότητες, κύρια/εναλλακτική ημέρα, αντικαταστάσεις, ειδικές ημέρες/διαστήματα, κοινόχρηστα δεδομένα και εκτυπώσεις.

## Νέα στη v0.32

### Νέα αρχική οθόνη
Η Αρχική λειτουργεί πλέον ως dashboard και εμφανίζει:
- τίτλο «Πρόγραμμα Δημιουργίας Εφημεριών»
- ονομασία σχολείου
- ενεργό σχολικό έτος
- αριθμό εκπαιδευτικών και αναθέσεων
- τρόπο εφημερίας
- αν τα δεδομένα είναι τοπικά ή κοινόχρηστα
- έκδοση εφαρμογής και αρχιτεκτονική `x86` / `x64`
- γρήγορα κουμπιά για Δημιουργία, Πρόγραμμα, Αντικατάσταση και Εκτυπώσεις

Η αρχιτεκτονική εμφανίζεται επίσης στη γραμμή κατάστασης και στον τίτλο του παραθύρου.

### Εικονίδιο εφαρμογής
Προστέθηκε `app_icon.ico` και τα build scripts το ενσωματώνουν στα x86/x64 EXE. Οι συντομεύσεις των Windows χρησιμοποιούν έτσι το εικονίδιο της εφαρμογής.

### Εκτύπωση ανά εκπαιδευτικό — «Όλοι οι εκπαιδευτικοί»
Στις Εκτυπώσεις μπορείς να επιλέξεις:
- συγκεκριμένο εκπαιδευτικό ή
- **Όλοι οι εκπαιδευτικοί**.

Στη δεύτερη περίπτωση δημιουργείται ενιαίο αρχείο εκτύπωσης και κάθε εκπαιδευτικός ξεκινά σε νέα σελίδα.

### Έλεγχος κύριας ημέρας
Στην ημερήσια παραγωγή η κύρια ημέρα εξακολουθεί να έχει προτεραιότητα. Μετά την παραγωγή εμφανίζεται έλεγχος με:
- αναθέσεις στην κύρια ημέρα
- αναθέσεις στην εναλλακτική ημέρα
- αναθέσεις εκτός κύριας/εναλλακτικής

Έτσι οι αναγκαίες αποκλίσεις είναι εμφανείς και ελέγξιμες.

### Έλεγχος αναδυόμενων παραθύρων
Τα αναδυόμενα παράθυρα προσαρμόζονται στην ανάλυση/κλιμάκωση των Windows, ανοίγουν εντός της οθόνης και παραμένουν μεταβλητού μεγέθους. Τα μεγάλα παράθυρα που ήδη διαθέτουν κύλιση συνεχίζουν να τη χρησιμοποιούν.

## Κοινόχρηστη χρήση x86 / x64
Στις **Ρυθμίσεις → Τοποθεσία δεδομένων / κοινόχρηστη χρήση** δήλωσε τον ίδιο κοινόχρηστο φάκελο και στις δύο εκδόσεις, π.χ.:

`C:\SchoolShare\Αρχεία Κοινά_Θανάσης\Εφημερίες\Shared`

Η προτεινόμενη δομή είναι:

```text
Εφημερίες\
├─ x64\
├─ x86\
└─ Shared\
   ├─ data\
   ├─ backups\
   └─ exports\
```

Η εφαρμογή δημιουργεί τους υποφακέλους `data`, `backups` και `exports` αν δεν υπάρχουν. Για προστασία της SQLite βάσης χρησιμοποιείται `.efimeries.lock`, ώστε να υπάρχει μία ενεργή συνεδρία επεξεργασίας κάθε φορά.

## Backup / μεταφορά σε νέα έκδοση
Στις Ρυθμίσεις υπάρχουν:
- **Πλήρες Backup σχολικού έτους**
- **Επαναφορά / εισαγωγή Backup**

Το `.efbackup` μεταφέρει εκπαιδευτικούς, διαθεσιμότητες, κύρια/εναλλακτική ημέρα, τομείς, χρονικές ζώνες, ειδικές ημέρες, πρόγραμμα, πραγματοποιημένες εφημερίες, αντικαταστάσεις, ιστορικό και ρυθμίσεις. Αυτή είναι η προτεινόμενη μέθοδος αναβάθμισης.

## Εισαγωγές / εξαγωγές
Υποστηρίζονται επίσης:
- εισαγωγή / εξαγωγή εκπαιδευτικών CSV
- εισαγωγή / εξαγωγή ειδικών ημερών CSV
- εισαγωγή / εξαγωγή προγράμματος εφημεριών CSV
- εξαγωγές εβδομάδας και αναφορών

## Επικόλληση
Υποστηρίζονται:
- `Ctrl+V` / `Shift+Insert`
- `Ctrl+C`
- `Ctrl+X`
- δεξί κλικ σε πεδία κειμένου με μενού αποκοπής / αντιγραφής / επικόλλησης

## Σχολικά έτη
- Διατηρούνται σχολικά έτη από **2026-2027** και μετά.
- Κάθε σχολικό έτος έχει ξεχωριστή βάση στο `data\years`.
- Κατά τη δημιουργία νέου έτους μπορούν να αντιγραφούν εκπαιδευτικοί, διαθεσιμότητες, τομείς, χρονικές ζώνες, τρόπος εφημερίας και στοιχεία σχολείου/εκτύπωσης.
- Δεν αντιγράφονται αυτόματα πρόγραμμα, πραγματοποιημένες εφημερίες, αντικαταστάσεις ή ειδικές ημέρες.

## Δημιουργία Windows εφαρμογής
Η προτεινόμενη μορφή είναι **portable φάκελος (PyInstaller onedir)**.

### x64
Τρέξε:

`build_x64.bat`

Παράγεται:

`dist\EfimeriesPortable_x64\EfimeriesPortable_x64.exe`

### x86
Απαιτείται ξεχωριστή Python 32-bit. Τρέξε:

`build_x86.bat`

Παράγεται:

`dist\EfimeriesPortable_x86\EfimeriesPortable_x86.exe`

### Και τα δύο
Αν υπάρχουν εγκατεστημένες 32-bit και 64-bit Python, τρέξε:

`build_both.bat`

Για μεταφορά σε άλλον υπολογιστή αντιγράφεις **ολόκληρο τον αντίστοιχο φάκελο** από το `dist`, όχι μόνο το `.exe`.

Τα `build_x64_onefile.bat` και `build_x86_onefile.bat` παραμένουν μόνο για δοκιμή. Η μορφή onedir είναι η προτεινόμενη επειδή είναι πιο σταθερή με Windows Defender/antivirus.


## v0.32 – διορθώσεις σταθερότητας

- Διορθώθηκε το τρέμουλο στο παράθυρο προσθήκης/επεξεργασίας εκπαιδευτικού: αφαιρέθηκε η συνεχής αυτόματη επανατοποθέτηση των αναδυόμενων παραθύρων.

## Τελική διανομή και προστασία κώδικα

- `build_x64.bat` / `build_x86.bat`: σταθερό build με PyInstaller.
- `build_protected_x64.bat` / `build_protected_x86.bat`: προαιρετικό obfuscated build με PyArmor + PyInstaller.
- `create_distribution.bat`: δημιουργεί πακέτο διανομής χωρίς `app.py`, `.bat` ή `.spec`.
- Η διανομή προς τελικούς χρήστες πρέπει να γίνεται από το παραγόμενο `release\EfimeriesPortable_v0_36_Distribution.zip`.
- Το Developer πακέτο πρέπει να διατηρείται ιδιωτικά.

Η προστασία/obfuscation δυσκολεύει σημαντικά την ανάκτηση της λογικής, αλλά κανένα desktop executable δεν είναι απολύτως μη αναστρέψιμο.

## v0.38 – αντικαταστάσεις εφημερίας

- Η αντικατάσταση γίνεται πλέον αποκλειστικά με επιλογή εκπαιδευτικού από λίστα.
- Οι υποψήφιοι χωρίζονται σε δύο ομάδες:
  1. Προτεινόμενοι/ες: πραγματικά διαθέσιμοι/ες και με τη συγκεκριμένη ημέρα δηλωμένη ως Κύρια ή Εναλλακτική.
  2. Λοιποί διαθέσιμοι/ες: πραγματικά διαθέσιμοι/ες αλλά χωρίς τη συγκεκριμένη ημέρα ως προτιμώμενη, για έκτακτη εθελοντική εξυπηρέτηση.
- Εκπαιδευτικός που έχει ήδη ανάθεση στην ίδια χρονική ζώνη αποκλείεται από τις λίστες.
- Σε εφημερία ανά διάλειμμα ή ανά βάρδια εξακολουθεί να ελέγχεται η πραγματική διαθεσιμότητα της συγκεκριμένης ζώνης/βάρδιας.
- Αν επιλεγεί εκπαιδευτικός από τη δεύτερη ομάδα, καταγράφεται αυτόματα στο ιστορικό ότι πρόκειται για εθελοντική εξυπηρέτηση εκτός δηλωμένης κύριας/εναλλακτικής ημέρας.
- Η πραγματική ανάθεση ενημερώνεται με τον αντικαταστάτη, επομένως εβδομαδιαίες, μηνιαίες, διαστήματος και ατομικές εκτυπώσεις εμφανίζουν αμέσως το διορθωμένο πρόγραμμα χωρίς αναδημιουργία.
- Η αντικατάσταση παραμένει στο ιστορικό και συνυπολογίζεται στις επόμενες κατανομές όταν κλειδώνεται ως πραγματοποιημένη.


## v0.38 – Αντικατάσταση εφημερίας
- Η πρώτη λίστα εμφανίζει προτεινόμενους/ες που είναι διαθέσιμοι/ες και έχουν τη συγκεκριμένη ημέρα ως κύρια ή εναλλακτική.

## v0.38 – Ανακατανομή και ετήσια εξισορρόπηση
- Η «Ανακατανομή από ημερομηνία και μετά» διαγράφει ρητά όλες τις μη κλειδωμένες μελλοντικές αναθέσεις και τις δημιουργεί ξανά.
- Οι κλειδωμένες/πραγματοποιημένες αναθέσεις, συμπεριλαμβανομένων των αντικαταστάσεων, παραμένουν και αποτελούν τη βάση των ετήσιων συνόλων.
- Στην ημερήσια εφημερία προστέθηκε δεύτερο συνολικό πέρασμα εξισορρόπησης για όλο το υπόλοιπο διάστημα, ώστε οι μελλοντικές αναθέσεις να προσαρμόζονται στα πραγματικά τελικά σύνολα.
